Annexe H. Comparaison des outils IA pour le développement

Le paysage des outils change d’un trimestre à l’autre. Cette annexe donne un état au 29 septembre 2026 des outils les plus utiles à un actuaire, avec leurs forces, leurs limites et leurs usages. Les prix de Claude sont ceux de claude.com/pricing à cette date ; ceux des autres éditeurs changent souvent et se vérifient sur leur site.

Les offres de Claude au 29 septembre 2026

En dollars hors taxes (claude.com/pricing). Claude Code est inclus dans tous les plans payants, pas dans l’offre gratuite.

Côté API, la documentation d’Anthropic (« Manage costs », code.claude.com/docs/en/costs) donne pour Claude Code un coût moyen d’environ 13 $ par développeur et par jour actif, 150 à 250 $ par développeur et par mois, et moins de 30 $ par jour actif pour 90 % des utilisateurs.

ImportantLa question avant le prix : les données

Tout ce qu’un assistant ou un agent lit part chez son éditeur. Les offres grand public et les offres entreprise ne se valent pas : seule une offre entreprise (chez Anthropic : Team, Enterprise, API avec contrat) fait de l’éditeur un sous-traitant de votre organisme au sens du RGPD. La même question se pose pour chaque outil du tableau, et se tranche avec la DSI et le délégué à la protection des données. Sur un compte grand public, vérifiez aussi dans les réglages si vos conversations peuvent servir à entraîner les modèles. Voir l’annexe G.

Recommandations par profil

Actuaire d’abord sur Excel, débutant en Python

  • Claude Code dans l’extension VS Code (niveau 2), pour les calculs Python dès qu’il y a une boucle écrire, exécuter, corriger. C’est l’objet de cette formation.
  • Un assistant conversationnel (niveau 1), sous l’offre que votre organisme autorise, pour les questions ponctuelles et les angles d’analyse.

À éviter au démarrage : Cursor (un éditeur de plus à apprendre), le SDK (il demande un savoir-faire d’ingénieur), la complétion de GitHub Copilot (peu utile quand on écrit peu de code soi-même).

Actuaire à l’aise en Python

  • Claude Code, dans VS Code ou dans le terminal (niveau 2), comme outil principal.
  • Un assistant conversationnel (niveau 1) pour les questions de fond.
  • GitHub Copilot en option, si vous écrivez beaucoup de code répétitif.

Après quelques mois, comparer avec un autre agent (Cursor, Codex CLI) si votre façon de travailler s’y prête.

Actuaire data avancé, équipe d’industrialisation

  • Claude Code (niveau 2) au quotidien.
  • Le SDK Anthropic (niveau 3) pour les outils métier : validation automatisée, production en lot, classification.
  • Lovable pour prototyper une interface quand Streamlit ou Dash ne suffisent pas, sur des données synthétiques ou agrégées.

Détail outil par outil

ChatGPT

Forces. Notoriété, écosystème large, mémoire entre conversations, applications mobiles abouties.

Limites. Dans l’interface conversationnelle, le code s’exécute dans l’environnement d’OpenAI, pas sur votre poste ni sur vos fichiers : on revient vite au copier-coller. Mêmes questions d’offre et de données que pour Claude.

Quand l’utiliser : questions ponctuelles ou conceptuelles, recherche d’angles d’analyse, premier jet d’un code court.

Claude (claude.ai)

Forces. Raisonnement long, rédaction et relecture de prose, lecture de documents longs (un PDF de plusieurs centaines de pages). Applications de bureau et mobiles.

Limites. La version web n’accède pas à vos fichiers locaux. Les offres Pro et Max sont des offres grand public : pas de données de clients dessus.

Quand l’utiliser : analyse de documents publics longs (un texte de l’ACPR, un rapport de place), rédaction et relecture d’une note, discussion de méthode.

Mistral Le Chat

Forces. Éditeur français, bon niveau en français.

Limites. Écosystème plus petit qu’OpenAI ou Anthropic, intégrations aux éditeurs de code moins nombreuses. Le contrat et le lieu d’hébergement se vérifient comme pour les autres : un éditeur européen ne dispense pas de choisir l’offre.

Quand l’utiliser : quand le cabinet préfère un éditeur européen, sous une offre adaptée aux données traitées.

Microsoft Copilot Chat

Forces. Intégré à Word, Excel, PowerPoint et Outlook. Utile pour la bureautique assistée : rédiger une note, mettre en forme, analyser un tableau Excel.

Limites. Pas fait pour le développement Python. Lié à l’écosystème Microsoft : un avantage si le cabinet y est déjà, une friction sinon.

Quand l’utiliser : rédiger une note dans Word, analyser un tableau sans quitter Excel. C’est aussi l’assistant que beaucoup d’organismes autorisent en premier : la démarche de la formation s’y applique, sans l’exécution automatique.

GitHub Copilot

Forces. Complétion dans l’éditeur, conversation intégrée à VS Code, et depuis 2025 un mode agent qui modifie les fichiers et lance des commandes, à la manière des agents du niveau 2. Bonne intégration à GitHub.

Limites. Un coût de plus si vous payez déjà un autre agent. Les mêmes questions de permissions et de données que pour Claude Code.

Quand l’utiliser : en complément pour la complétion, ou comme agent principal si votre organisme a déjà une licence.

Claude Code

Forces. Agent complet : il lit, modifie et exécute du code sur votre poste. Plusieurs surfaces (terminal, VS Code, JetBrains, application de bureau, web, mobile). Mémoire de projet par CLAUDE.md et .claude/rules/, mode plan, skills, sous-agents, hooks, bac à sable hors Windows natif.

Limites. Un coût qui monte en usage intensif sur l’API (150 à 250 $ par développeur et par mois selon la documentation d’Anthropic). Une courbe d’apprentissage sur les permissions et la mémoire. Sous Windows natif, pas de bac à sable : la protection des données repose sur leur absence du dossier.

Quand l’utiliser : votre outil principal au niveau 2, après cette formation.

Codex CLI et Gemini CLI

Forces. Les agents en ligne de commande d’OpenAI et de Google, de la même famille que Claude Code : ils lisent, modifient et exécutent sur votre poste.

Limites. Les mêmes questions que pour Claude Code : permissions, offre, données.

Quand l’utiliser : si votre organisme a déjà un contrat avec l’un de ces éditeurs. La démarche de la formation s’y transpose sans changement.

Cursor

Forces. Éditeur complet dérivé de VS Code, agent intégré, choix entre plusieurs modèles.

Limites. Un éditeur de plus à apprendre. Un tarif qui dépend de l’usage.

Quand l’utiliser : en alternative à Claude Code si vous préférez un éditeur dédié à une extension. À comparer après quelques mois de Claude Code.

Cline

Forces. Open source, extension VS Code, avec votre propre clé d’API : vous payez le modèle au token, directement.

Limites. Moins abouti que Claude Code ou Cursor. La clé d’API se configure soi-même, et se protège.

Quand l’utiliser : pour comprendre la mécanique interne d’un agent, ou pour suivre le coût au plus près.

Aider

Forces. Outil léger en ligne de commande, centré sur Git : chaque modification donne un commit. Rapide à démarrer.

Limites. Pas d’interface graphique ; un démarrage rude sans habitude du terminal.

Quand l’utiliser : utilisateurs à l’aise dans le terminal, travaux scriptés.

Lovable

Forces. Lancé fin 2024 (ex GPT Engineer). Construit des applications web (React) en langage naturel, avec leur partie serveur et leur base de données hébergées, et les met en ligne en un clic.

Limites. L’application et ses données sont hébergées chez Lovable : données agrégées ou synthétiques seulement. Une application JavaScript n’importe pas un module Python : pour réutiliser un moteur de calcul, il faut une API entre les deux. L’option locale existe : un tableau de bord Streamlit construit par Claude Code sur le poste.

Quand l’utiliser : pour prototyper l’interface d’un tableau de bord quand Streamlit ou Dash ne suffisent pas visuellement.

SDK Anthropic

Forces. Appeler le modèle depuis vos programmes Python : validation automatisée, production en lot, classification, explication d’un résultat à qui le lit.

Limites. Il demande un savoir-faire d’ingénieur : gestion des appels, des erreurs, des coûts, du suivi.

Quand l’utiliser : au niveau 3, quand le besoin est récurrent, automatisable, et touche plusieurs collègues. Le chapitre « Les formes d’appel » (partie 4) en montre les premières formes.

Ce qui bouge

État au 29 septembre 2026.

Le pattern Advisor. Le billet d’Anthropic « The advisor strategy » (9 avril 2026) décrit un outil de l’API, en bêta, où un modèle rapide consulte un modèle plus fort quand il en a besoin. Les chiffres publiés : Haiku conseillé par Opus passe de 19,7 % à 41,2 % sur le banc d’essai BrowseComp et coûte 85 % de moins par tâche que Sonnet seul, mais reste en dessous du score de Sonnet ; Sonnet conseillé par Opus gagne 2,7 points sur SWE-bench Multilingual pour un coût inférieur de 11,9 %. Des gains réels sur des bancs d’essai précis, pas une division des coûts à généraliser (claude.com/blog/the-advisor-strategy).

Les Routines et l’automatisation. Lancées en préversion le 14 avril 2026 et présentées à la conférence Code w/ Claude du 6 mai, les Routines font tourner Claude Code sur des tâches asynchrones, sans session ouverte. Avec le mode non interactif (claude -p) et l’intégration à GitHub Actions, Claude Code est aussi un outil d’automatisation, pas seulement un outil interactif.

Les modèles. Opus 5.5 (claude-opus-5-5) est le modèle par défaut de Claude Code ; Sonnet 5.5 (claude-sonnet-5-5) est le Sonnet actuel ; Haiku 4.5 peut être retiré dès le 15 octobre 2026. Un code qui cite claude-sonnet-4-6 est daté.

Le cadre réglementaire. Les règles de l’AI Act sur le haut risque s’appliquent au 2 décembre 2027, et l’ACPR a soumis à consultation un document sur l’équité algorithmique jusqu’au 30 septembre 2026. Voir l’annexe G.

TipExercice : quel outil, quelle offre ?
  1. Votre DSI n’autorise que GitHub Copilot, sous licence entreprise. Un collègue soupire : « Copilot ne fait que suggérer, on va tout copier-coller, la formation ne sert à rien. » Que lui répondez-vous ?
  2. Pour essayer Claude Code sur un extrait pseudonymisé du portefeuille, une collègue propose de prendre un abonnement Pro à ses frais. Bonne idée ?
Voir la réponse
  1. Copilot a un mode agent depuis 2025 : il modifie les fichiers et lance des commandes. Et la démarche ne dépend pas de l’outil : intention avant code, petits pas, chiffres produits par un code exécuté, critique demandée, commits. Les questions de permissions et de données se posent de la même façon.
  2. Non. Pro est une offre grand public : Anthropic n’y est pas le sous-traitant de votre organisme, et une donnée pseudonymisée reste une donnée personnelle. L’essai se fait sur des données synthétiques ou publiques ; le passage aux vraies données attend une offre entreprise validée par la DSI et le délégué à la protection des données.
